# HFT Dashboard

A High-Frequency Trading (HFT) analytics dashboard for real-time market data visualization and performance monitoring.

> Fork -- customized and extended for personal learning and experimentation.

## Overview

The HFT Dashboard gives traders and researchers a real-time view of market microstructure data -- order flow, latency metrics, tick data analysis, and strategy performance.

## Features

- Real-time market data -- live tick data streaming with WebSocket
- Latency monitoring -- order execution latency histograms and percentiles
- Order book visualization -- live bid/ask depth chart
- P&L tracking -- real-time profit/loss curves per strategy
- Alerts -- configurable threshold-based market alerts
- Strategy performance -- Sharpe ratio, drawdown, win rate metrics

## Getting Started

```bash
git clone https://github.com/atharvez/HFT-Dashboard.git
cd HFT-Dashboard
npm install
npm run dev
```
